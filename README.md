Entry for the SPE Europe Geohackathon - first place winner.

This code takes images from seismic data and petrophysical data, applying a U-Net architecture to predict rock properties from the seismic data (pre-stack and post-stack)

For more information, please read our team's paper: 
https://onepetro.org/SPEEURO/proceedings-abstract/24EURO/24EURO/546512
